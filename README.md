## 🚀 Setup & Updating

### 1. Requirements
- Requires [**MicroG RE**](https://github.com/MorpheApp/MicroG-RE/releases) installed to log in to your Google Account.
- Standard 64-bit Android device (ARM64).

### 2. Auto-Updates with Obtainium
1. Install [**Obtainium**](https://github.com/ImranR98/Obtainium).
2. Click **[Import to Obtainium]** above to add this repository.
3. Obtainium will automatically track every new release and notify/install updates with 1 tap.

### 3. In-App Updates
You can also check for updates directly inside YouTube Music:  
`Settings` → `Morphe` → `Build update`.
